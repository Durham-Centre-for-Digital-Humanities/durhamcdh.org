Durham University Alumni in the Great War: A Memorial Database

A biographical database of Durham University alumni who fell in the First World War, 1914–1918.

About this project

This project created a searchable biographical database of Durham University alumni who died during the First World War. Working from the University War Memorial Register held in Palace Green Library, records were transcribed and cross-referenced with the Commonwealth War Graves Commission database, regimental histories, and university matriculation records.

The database covers 147 individuals across all Durham colleges, recording university career, military service, date and place of death, and memorial commemoration. The project website provides a searchable, filterable table of all records and an interactive map plotting places of burial.

On completion, the SQLite database was exported to JSON and the site rebuilt to read from those flat files, allowing it to be hosted as a static archive without any server-side infrastructure.

Data & Methodology

Records were transcribed from the Durham University War Memorial Register (Palace Green Library, Special Collections) and verified against the Commonwealth War Graves Commission Debt of Honour Register and the Soldiers Died in the Great War dataset. Matriculation years and college affiliations were confirmed against Durham University Calendar editions.

The original project was built as a Flask web application with a SQLite backend. On project completion, data was exported to JSON using a Python export script and the front end adapted to read from the JSON files directly, removing the Flask dependency and enabling static hosting.

Data

50 records in this archived sample (full database: 147). Fields: surname, forenames, college, matriculation year, rank, regiment, date of death, place of death, memorial, Wikidata ID, notes.
